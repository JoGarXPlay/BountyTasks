# BountyTasks

BountyTasks is a Minecraft plugin that allows players to take on tasks, complete objectives, and earn rewards.

## Features

* Randomly selected tasks
* Task books
* Configurable tasks and rewards
* Multi-language support
* Spanish and English
* Simple GUI
* Free to use

## Download

Download the latest official version of BountyTasks from the [GitHub Releases](../../releases) page.

Only download BountyTasks from official or officially authorized sources.

## Installation

1. Download the latest `BountyTasks-x.x.x.jar` from the Releases page.
2. Place the `.jar` file into your server's `plugins` folder.
3. Start or restart the server.
4. BountyTasks will generate its configuration files automatically.

## Commands

`/bountytasks`
`/bt`

Open the BountyTasks menu.

### Reload

`/bountytasks reload`
`/bt reload`

Reloads the BountyTasks configuration.

**Permission:** `bountytasks.reload`

## Configuration

BountyTasks supports configurable tasks and rewards through `tasks.yml`.

Language settings can be configured through `config.yml`.

## Languages

Currently supported languages:

* Spanish (`es`)
* English (`en`)
